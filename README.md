# Нефтяные войны — устройство проекта

**Куда класть новый файл — таблица в разделе «Правила проекта».** Если сомневаешься,
клади в тот каталог, который отвечает на вопрос «откуда это взялось», а не
«что это за формат».

Проект — фанатский редизайн настольной игры **Cthulhu Wars** в сеттинге
индустриального киберпанка XXIV века. Механика оригинала сохраняется 1:1,
меняются тема, оформление и компоненты. Предметный контекст — `CLAUDE.md`.

---

## Структура

Семь каталогов верхнего уровня. Глубина дерева — не больше трёх уровней.

| Каталог | Что внутри | Чего там не бывает | Основной потребитель |
|---|---|---|---|
| `source/` | Чужое и входящее: оригинал Cthulhu Wars, экспорты наших гуглдоков | ничего нашего и ничего изменённого | агент, человек |
| `rules/` | Наш текст правил, реестры, решения, скрипты сборки | арт, компоненты, поле | агент |
| `board/` | Игровое поле: геометрия, области, смежности, эскизы, скрипты | правила, арт компонентов | агент, скрипты |
| `print/` | HTML/CSS/JS-генераторы печатных компонентов и их ассеты | исходники арта, документы проекта | браузер, человек |
| `acrylic/` | Готовый арт под акриловую резку | всё, что не идёт в резку | типография |
| `art/` | Оформление и его исходники: иллюстрации, логотипы, шрифты, референсы | готовые компоненты | человек |
| `archive/` | Снятое с работы, но не удалённое | всё, на что ссылается работающий файл | никто |

В корне лежат только `README.md`, `CLAUDE.md`, `.gitignore` и
`Инвентаризация компонентов.xlsx`. Больше в корень ничего не кладётся.

### Источники истины

Один вопрос — один файл. Конкурирующих источников быть не должно.

| Вопрос | Источник истины |
|---|---|
| Как работает правило | `rules/RULEBOOK.md` |
| Числа, термины, иконки, расхождения | `rules/registry/*.yaml` |
| Какие области на поле и что с чем граничит | `board/regions.yaml`, `board/edges.yaml` |
| Состав и свойства фракции | `print/Saved/Faction Card — *.pdf` |
| Как пишется название фракции | `CLAUDE.md` §2 |
| Стиль иллюстраций | `art/ArtBible.md` |
| Что вообще есть в коробке и в каком статусе | `Инвентаризация компонентов.xlsx` |

Всё остальное — производное. Если производное разошлось с источником, правится
источник и пересобирается производное, а не наоборот.

## Правила проекта

### Куда класть новый файл

| Что появилось | Куда |
|---|---|
| Материал оригинальной Cthulhu Wars | `source/cthulhu-wars/` |
| Новый экспорт нашего гуглдока | `source/gdocs/` |
| Правка правил, реестра, решения | `rules/` |
| Что угодно про игровое поле | `board/` |
| Ассет или шаблон печатного компонента | `print/` |
| Картинка под акриловую резку | `acrylic/`, по конвенции имени из `CLAUDE.md` §5 |
| Иллюстрация, логотип, шрифт, референс | `art/` |
| Отвергнутый вариант, старая версия, снятый с работы файл | `archive/` |

Черновиков как отдельного каталога нет. Незаконченное живёт там же, где
законченное, и отличается статусом в реестре или в `Инвентаризация компонентов.xlsx`,
а не расположением. Отдельный каталог заводится только тогда, когда в нём
окажется больше трёх файлов одного назначения.

### Как называть файлы

1. По-русски, кроме `print/`, `rules/tools/`, `board/tools/` и `board/geo/` — там латиница, так исторически и так безопаснее для скриптов.
2. Никаких `new`, `final`, `latest`, `v2`, `_старое`, `копия`. Актуальная версия — та, что лежит на своём месте; неактуальная — та, что лежит в `archive/`.
3. Версия в имени допустима только там, где версии сосуществуют осознанно и одновременно (`art/doomsday/3 игрока v1.1.png`). Тогда версия пишется как `v1.1` в конце, перед расширением.
4. Дата в имени — только `ГГГГ-ММ-ДД` и только там, где файл привязан к моменту (снимок, экспорт, архив).
5. Файлы под акрил — строго по конвенции `NN. Название - тип - количество - размер.png` из `CLAUDE.md` §5.

### Как отличить актуальное от старого

Актуальное лежит в рабочем каталоге. Старое лежит в `archive/`. Третьего состояния нет.
Файл не помечается словом в имени — он переносится.

### Что в Git, что нет

В Git идёт всё, кроме перечисленного в `.gitignore`. Из Git исключены три вещи:

1. **Тяжёлое и невосстановимое** — `board/legacy/` (2.7 ГБ старых PSD поля), рулбуки оригинала, крупные архивы и PSD в `source/cthulhu-wars/`. GitHub не принимает файлы больше 100 МБ.
2. **Производное** — `rules/registry/registry.db`, `__pycache__/`, `print/Saved/*.pdf`.
3. **Снятое с работы** — весь `archive/`.

> Исключение из Git не означает, что файл можно удалить. Единственный экземпляр
> всего исключённого лежит в этой папке на Яндекс.Диске и больше нигде.
> Прежде чем удалить исключённый файл, надо понять, воспроизводится он или нет.

Файл считается производным и не хранится в Git, если его можно получить заново
запуском скрипта из таблицы «Что чем собирается» или повторной печатью из `print/`.

### Временные файлы

Временных файлов в проекте не бывает. Промежуточный результат либо становится
частью каталога, где он нужен, либо удаляется в ту же сессию. Каталога `tmp/` нет
и заводить его не надо.

## Как запускать

```
python rules/tools/registry.py all        # пересобрать реестры и отчёты правил
python rules/tools/build_rulebook.py      # пересобрать RULEBOOK.md из черновиков
python rules/tools/qa_final.py            # финальная QA по книге
python board/tools/map.py all             # пересобрать раскладки поля и board/reports/11-map.md
python board/tools/worldgeom.py all       # пересобрать эталонную географию
```

Скрипты определяют пути от собственного расположения — запускаются из любого каталога.
Зависимости: `pyyaml`, `numpy`, `shapely`, `Pillow` (для части скриптов поля).
