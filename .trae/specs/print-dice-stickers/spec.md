# Dice Stickers Print Layout Spec

## Why
Необходимо создать production-ready HTML+CSS макет для точной печати 120 наклеек (размер 13x13 мм) на грани кубиков d6. Печать будет производиться на прозрачной пленке формата A4, поэтому критически важно соблюсти точные размеры, правильные метки реза (крестики) и избежать искажений.

## What Changes
- Создание или обновление `Dices.html` с сеткой из 120 ячеек.
- Создание или обновление `./dices/dices.css` с точными размерами в миллиметрах.
- Настройка CSS сетки (grid, 14 колонок по 13mm), центрированной на странице.
- Добавление крестиков для реза на стыках и углах ячеек.
- Подключение локального шрифта `AlienEncounters.ttf` для цифр.
- Применение CSS-правил для точной печати (`print-color-adjust`, отсутствие сглаживания).

## Impact
- Affected specs: Создание макета для печати наклеек.
- Affected code: `Dices.html`, `dices/dices.css`.

## ADDED Requirements
### Requirement: A4 Print Layout
- Формат страницы A4, отступы 10мм.
- Точные размеры ячейки/наклейки 13x13мм (без округлений).
- Без отступов (margin/padding) внутри ячеек, картинки `object-fit: contain`.

### Requirement: Cut Marks
- Чёрные крестики для реза по углам ячеек и на стыках, без сплошных рамок.

### Requirement: Content Grouping
- Строго 120 ячеек, сгруппированных по типам (kill, retreat, 1, 2, 3) с HTML-комментариями.

### Requirement: Font & Visuals
- Локальный шрифт `AlienEncounters.ttf`, цвет `#00ffff`, центрировано, размер ~85% ячейки (высота).
- Никаких теней, градиентов, антиалиасинга. Белый фон страницы, `print-color-adjust: exact`.
- Только HTML и CSS (без JS, Canvas, инлайн SVG).
