## 3. Как устроен чат по фракции

1. Прочитать `print/Faction-Card-A/README — шаблон планшета.md` (схема данных)
   и раздел этой фракции в §4 ниже.
2. Свериться с `rules/registry/factions.yaml` — состав отрядов, стоимости, силы.
   Расхождение не чинить молча: вынести списком, решение за Alek (`CLAUDE.md` §3).
3. Править **только** `Данные/<Фракция>.json`. Оформление — в шаблоне, его не трогать.
4. `python3 Сборка.py <Фракция>` → открыть `Планшет — <Фракция>.html`,
   печать Ctrl+P → A4 альбомная → 100 % → фон включить. Сборка проверяет
   кавычки (`D-075`, только “ ”): не собралось — исправить в указанном поле.
   Карты и другие компоненты перед сдачей — `python3 print/check_quotes.py`.
5. Записать результат назад: строку чата в §2 этого файла, решения — в
   `rules/DECISIONS.md`, состояние компонента — в `components.yaml`.

**Номер решения берётся после перечитывания хвоста `DECISIONS.md`, а не по памяти.**
При параллельных чатах номера уже сталкивались дважды.
