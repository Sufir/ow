4. Отчёт: метрики всех областей трёх полотен, выдача `boardcheck`.

## Как работать с Alek

- Результат Alek смотрит в браузере по сборке, не по текстам. Вопросы — в чате,
  не в отчётах. Площади и балансы считать самому по числам.
- Картинки в чат не присылать. Один вопрос — один блок: контекст, варианты,
  рекомендация.

## Техника

- Среда — компьютер Alek через связанную оболочку: `python3`, `numpy`, `shapely`,
  `scipy`, `pyyaml`. Docker не нужен.
- Пересборка всего: `python3 board/tools/classic.py all`, затем
  `python3 board/tools/slice5.py all`, затем сборка трёх полотен.
- Git — `git --no-optional-locks` для статуса и лога. Файлы `source/*.mhtml`
  в коммит не брать. Удалять файлы в папке можно только с разрешения Alek —
  иначе строкой в очередь уборки.
- Файл, отданный на компьютер повторно под тем же именем, может записаться
  старой копией: отдавать каждый раз под новым именем и сверять md5.
