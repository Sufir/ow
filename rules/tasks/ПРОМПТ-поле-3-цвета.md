## Градиент между океанами — требования

1. Только граница океан — океан. Океан — суша и суша — суша — строгая линия.
2. Узкий и симметричный: середина перехода — на самой границе области.
   Ширину показать двумя-тремя вариантами на тестовой странице.
3. Склейка краёв: границы океанов на левом и правом краю стоят на высоте
   78 и 272 мм. Переход у левого края должен совпадать с переходом у правого.
4. Панамский пролив — ребро Север Атлантики — Север Тихого шириной 8,6 мм.
   Градиент не должен его размыть до нечитаемого.
5. Способ — на выбор чата, с проверкой в браузере. Одна из дорог: слой

## Контраст — считать, а не на глаз

Скрипт считает для каждого ребра каждой из четырёх раскладок разницу светлоты
(ΔL*) и цвета (ΔE2000) и выдаёт таблицу: самые слабые пары, по полотнам.
Порог предлагает чат, подтверждает Alek по тестовой странице. «Светлые рядом
с тёмными» — это в первую очередь ΔL*.

## Техника

- Среда — компьютер Alek через связанную оболочку: `python3`, `numpy`, `pyyaml`.
  `shapely` и `scipy` в свежей сессии может не быть: `pip install shapely scipy`.
  Docker не нужен.
- Git — `git --no-optional-locks` для статуса и лога. Файлы `source/*.mhtml`
  в коммит не брать.
- Удалять файлы в папке можно только с разрешения Alek — иначе строкой в очередь
  уборки. Коммит без этого разрешения оставляет `.git/HEAD.lock` и `tmp_obj_*`
  в `.git/objects`: следующий коммит упадёт. Перед коммитом попросить разрешение
  на удаление и после коммита убрать только их.
- Файл, отданный на компьютер повторно под тем же именем, может записаться
  старой копией: отдавать каждый раз под новым именем и сверять md5.
