# CODE-02 — ОТМЕНЕНА

**Дата отмены:** 2026-09-10. **Основание:** `D-014`, `RULE-001`.
**Выполнять не нужно.** Файл оставлен, чтобы будущая сессия не завела задачу заново.

## Что было

Задача просила восстановить структуру четырёх табличных кусков, которые разваливает
`pdftotext`: таблицу эффектов Colour Gates из оригинала, наши «Особые фабрики»
и «Уникальные полковники» из `source/gdocs/pdf/`, а также листы карт Ultimate Errata Pack.

## Почему отменена

1. **Таблица Colour Gates и «Особые фабрики».** У нас эта таблица реализована
   отдельными картами формата таро. Это компонент, а не текст правил: в рулбук идёт
   только механика создания особых фабрик и бросок кубика в начале фазы Doom.
   Сверять таблицы построчно нужно будет при выверке карт — отдельной задачей,
   вне работы над правилами.
2. **«Уникальные полковники».** У нас полковники напечатаны на планшетах фракций
   вместе с пехотинцами, там же их свойство. В правилах достаточно описать тип
   отряда; таблица не нужна.
3. **Величина Power за Unspeakable Oath** — то, ради чего просили листы эрраты, —
   найдена без Code, в вики Cthulhu Wars: **2 Power**, и это сходится с примером
   в самом рулбуке. `BL-UNIT-012` закрыт, `GAP` в baseline не осталось.

## Что из этого может понадобиться позже

При выверке компонентов (не правил) пригодятся PNG-развороты страниц 143–144
`SRC-RB-NEW` — там оригинальная таблица эффектов Colour Gates, с которой нужно
будет сверить наши карты таро. Тогда и заводить задачу, с актуальными границами.
