**Промпт:** `rules/tasks/ПРОМПТ-поле-1-нарезка-5P.md`. **Решение:** `D-097`.
**Статус:** проверка зелёная — 0 отказов, 7 предупреждений: шесть «U ниже нормы 85» и Панамский пролив 8,6 мм.
Три круга правок по замечаниям Alek.

## Итог

Основа режется на 21 область: граф держится целиком, пороги `SPEC-BOARD` §6
проходят все 21. Ниже нормы 85 по U — шесть областей: это предупреждения,
не отказы. Смотреть — `board/geo/board-MC-5P.html`: области с id и метриками,
граф поверх карты, острова-декор, черновик, контур основы, склейка краёв.

## Как построено

1. **`board/tools/boardcheck.py`** — приёмка по вектору. Формат, смежности
   через шов (сдвиг ±880 мм), край полотна, U / N / U/A по `SPEC` §5–§6
   на развёрнутой через шов геометрии, целостность материков. Код 1 при любом
   отказе; `selftest` — 21 заведомо плохой вход, все пойманы.
2. **`board/tools/slice5.py`** — нарезка разрезами-ломаными по суше и по воде,
   куски раздаются по зёрнам. У каждого разреза причина. Заготовка `partition.py`
   (растр, под полярную) не пригодилась — отправлена в архив через очередь уборки.
3. **`board/tools/classic.py`** — правки основы, каждая строкой в `CORRECTIONS`.
   Все принимал Alek по сборке; список ниже.

## Как пересобрать

1. `python3 board/tools/classic.py all` — основа, около 30 с.
2. `python3 board/tools/slice5.py all` — нарезка, проверка и выдача, около 10 с.
3. Зависимости: `numpy`, `shapely`, `scipy`, `pyyaml`
   (`pip install shapely scipy`). Docker не нужен.
