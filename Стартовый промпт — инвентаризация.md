# Стартовый промпт для нового чата — инвентаризация компонентов

Скопировать всё, что ниже разделителя, в новый чат.

---

Проект — настольная игра «Нефтяные войны», папка открыта. **Сначала прочитай
`CLAUDE.md` в корне** — там состав фракций, источники, глоссарий и правила работы
с расхождениями. Дальше по этой задаче.

## Что нужно сделать

Инвентаризация всех компонентов игры со сверкой по оригинальной Cthulhu Wars.
Итог — таблица `Инвентаризация компонентов.xlsx` в корне папки проекта.

Три шага:

1. **Собрать состав оригинальной Cthulhu Wars** — базовая коробка и дополнения.
   Источник — [Cthulhu Wars Wiki](https://cthulhuwars.fandom.com/wiki/) и другие
   материалы в сети. Нужны точные количества: фигурки по типам, врата, кубики,
   маркеры Doom и Power, карты Spellbook, Acolyte, поле, треки. Отдельно —
   что добавляют дополнения (Onslaught 1/2/3, отдельные фракции, Glass Onion
   и прочее), потому что часть наших вариантов игры родом оттуда.
2. **Собрать наш состав** — из черновика правил (раздел «Компоненты»), дока
   фракций, готовых PDF в `Templates/Saved/` и файлов в `Под Акрил/`.
3. **Свести в одну таблицу** и выписать расхождения.

## Структура таблицы

Лист «Компоненты», колонки строго в этом порядке:

| Колонка | Что в ней |
|---------|-----------|
| Раздел | см. список разделов ниже |
| Компонент — наш нейминг | как называется у нас |
| Компонент — оригинал | как называется в Cthulhu Wars, по-русски и по-английски |
| Кол-во у нас | число |
| Кол-во в оригинале | число, с пометкой «база» или названием допа |
| Источник нашего числа | правила / док фракций / файл в папке / выведено |
| Носитель | миниатюра / акрил / карта / картон / планшет / поле |
| Где лежит | путь к файлу или PDF, если есть |
| Статус арта | `готово` / `требует доработки` / `не сделано` / `нет носителя` |
| **Готовность** | **оставить пустой, заполняет Alek вручную**: напечатано / подготовлено / упущено |
| Расхождения и примечания | коротко |

Колонку «Готовность» сделать с выпадающим списком из трёх значений и оставить
незаполненной. Ширины колонок подогнать, заголовок закрепить.

### Разделы таблицы

1. **Общие компоненты** — поле, треки, кубики, фабрики, скрытое влияние, маркеры,
   памятки, правила.
2. **Компоненты фракции** — по каждой из 8 фракций: пехотинцы, боевые машины,
   боевой робот, планшет, карты целей, карты технологий, маркер фракции,
   уникальные жетоны.
3. **Варианты игры** — особые фабрики, полковники, уникальные полковники,
   наёмники, лаборатория и энграммы, рой боевых дронов, баланс сил.
4. **Сверх оригинала** — то, чего в Cthulhu Wars нет, а у нас есть. Помечать явно.
5. **Из оригинала не берём** — то, что в Cthulhu Wars есть, а у нас нет. С причиной.

Второй лист — «Расхождения»: строка на каждый конфликт, колонки «Компонент»,
«Что говорят правила», «Что говорит док фракций», «Что в оригинале CW»,
«Что в файлах», «Предложение», «Решение Alek» (пустая).

## Правила работы

Ни один источник не истина в последней инстанции. Правила черновые и не вычитаны.
Расхождения не разрешать молча: выносить на лист «Расхождения» с предложением,
решение принимает Alek. У каждого числа указывать, откуда оно взято.

## Что уже выяснено — не переделывать

**Состав — 8 фракций**, эталонные написания в `CLAUDE.md`. Криогеник Технолоджис,
Свет Истины и Армия освобождения — вне состава.

**Юниты — покупные пластиковые миниатюры**, арт под них не нужен. На акрил идут
только жетоны и служебные стенди.

**Из раздела «Компоненты» черновика правил:** памятки 5, маркеры нефти 10,
игровое поле 2/4 половины, трек Судного дня 2, маркер Судного дня 1, трек влияния 1,
кубики d6 20, жетон первого игрока 1, военные фабрики 24, карточки скрытого
влияния 36 (18×1, 12×2, 6×3), планшеты по 1 на фракцию, карты целей по 6,
карты технологий по 6, маркеры фракций по 1. Уникальное: нефтяные вышки 12
(Глобал Петролеум), жетоны «Община» 4 (Братство), планшет «Луна» 1 (Moon Systems).
Варианты: особые фабрики 10, карты событий 6, фигурки полковников по 1 на фракцию,
карты уникальных полковников 11.

**Известные дыры в правилах:** количества для наёмников, лаборатории, энграмм
и роя не заданы нигде. Число фракций в правилах не названо. «Игровое поле 2/4 шт»
двусмысленно.

**Известные конфликты, которые надо занести на лист «Расхождения»:**
жетоны «Община» — правила говорят 4, док фракций «3 символьные + 1 бессимвольная»,
в `Templates/Saved/Factory Tokens v2.pdf` на стр. 2 их 8;
нефтяные вышки — правила 12, док фракций количество не задаёт;
терминологический разнобой «карточки скрытого влияния» / «жетоны влияния»
в одном документе.

**Состояние `Под Акрил`** — файлы 01–07, детали в `CLAUDE.md`, раздел 5.
Логотипы (07) пересобраны и готовы. Остальное — по таблице там же.

**Готовые печатные компоненты** лежат в `Templates/Saved/`: восемь планшетов
фракций, карты скрытого влияния, технологии и задачи, жетоны фабрик, карты событий,
уникальные полковники, трек Судного дня, наклейки на кубики.

## Как отдать результат

Файл `Инвентаризация компонентов.xlsx` в корне проекта. В чат — короткая сводка:
сколько позиций всего, сколько без арта, сколько конфликтов, и три-четыре самых
неприятных находки. Не пересказывать таблицу целиком.
