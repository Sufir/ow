# .agents — служебная директория работы над правилами

Здесь живёт всё служебное для одной большой задачи: **привести правила «Нефтяных войн»
к состоянию профессионально изданного рулбука, сохранив механику Cthulhu Wars 1:1.**

Работа рассчитана на несколько сессий. Директория — точка восстановления контекста:
любая новая сессия начинается с чтения `STATE.md`, дальше по ссылкам.

## Что где

| Путь | Что это |
|------|---------|
| `STATE.md` | **Читать первым.** Где мы остановились, что следующее, что блокирует |
| `RULES-CHARTER.md` | Инструкция: роль, принцип 1:1, иерархия источников, политика issue и редактуры |
| `PLAN.md` | План фаз P0–P12: цель, вход, выход, критерий готовности, статус |
| `DECISIONS.md` | Журнал решений Alek. Append-only, каждое решение = `D-###` |
| `registry/` | Машиночитаемые реестры (YAML — источник истины) |
| `registry/SCHEMA.md` | Описание всех схем и словарей значений |
| `sources/` | Исходники: экспорт нашего черновика и материалы оригинала |
| `tools/` | Скрипты: валидация реестров, сборка SQLite, генерация отчётов |
| `out/` | Черновые сборки рулбука до чистовика |

## Правило хранения

- Источник истины для реестров — **YAML** в `registry/`. Он человекочитаемый и
  правится руками.
- SQLite (`registry/registry.db`) — **производный артефакт**, собирается скриптом
  из YAML. Руками не правится, в случае расхождения пересобирается.
- Отчёты в `out/` — тоже производные. Правится YAML, отчёт пересобирается.

## Границы задачи

Работаем **только над правилами**. Карты, жетоны, планшеты, арт, составы фракций,
количества компонентов — **вне этой задачи**, даже если по ходу видны проблемы.
Замеченное по компонентам не чиним, а складываем в `issues.yaml` с
`type: OUT-OF-SCOPE` и разбираем отдельной задачей.

Общий контекст проекта — `../CLAUDE.md`.
